# CEP Language

Syntax highlighting for the CEP rule language (`.cep` files, `language cep/0.1`) in VS Code.

## Install

Download `cep-<version>.vsix` from the [GitHub Releases](https://github.com/VORSAR/cep-vscode/releases), then run:

```
code --install-extension cep-<version>.vsix
```

This is a preview; the plan, the release ladder and the status are in [docs/PLAN.md](docs/PLAN.md).
